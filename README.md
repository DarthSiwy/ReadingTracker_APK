# 📚 Reading Tracker

Aplikacja mobilna na system Android służąca do monitorowania postępów w czytaniu książek.

## Opis

Reading Tracker pozwala użytkownikom śledzić postępy w czytaniu książek poprzez zapisywanie informacji o książkach oraz aktualizowanie liczby przeczytanych stron. Aplikacja automatycznie oblicza procent ukończenia każdej książki i prezentuje postępy w przejrzysty sposób.

## Funkcjonalności

* Dodawanie nowych książek
* Edycja informacji o książkach
* Usuwanie książek z listy
* Śledzenie liczby przeczytanych stron
* Automatyczne obliczanie postępu czytania
* Oznaczanie książek jako ukończonych
* Przegląd wszystkich zapisanych książek
